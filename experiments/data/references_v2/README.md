# references_v2 — seeded + greedy references after the Gumbel-spike clamp

Commit `cef4f342` ("sampling: clamp curand uniform below 1.0f to kill Gumbel
noise spike") changed every seeded trajectory: `curand_uniform` maps the top
128 u32 draws to exactly 1.0f, `uniform2gumbel(1.0f)` degenerated to +46.05
(vs +16.3 max legitimate), deterministically force-sampling garbage tokens
(~0.005/row/step; ~2 victims with logprob < -20 per 437-token seeded 1.7B
run). The fix clamps the uniform to the largest float below 1.0f
(`fminf(u, 0x1.fffffep-1f)`) before the Gumbel transform — pure per-draw,
no RNG state/order change, so runs remain bitwise deterministic but all
pre-fix seeded references/dumps are superseded.

## Files (generated by experiments/validation/refv2_run.sh via refv2_client.py)

- `seeded_1p7b.json` — Qwen/Qwen3-1.7B, `--deterministic --capture-logprobs
  --sampling-seed 42 --ignore-eos --max-seq-length 512
  --max-num-batched-tokens 16 --pinned-ring-capacity 32`,
  `MPK_DET_NUM_SPLITS=4`, single request, canonical prompt embedded in
  refv2_client.py (GSM8K train[0] + e52 instruction suffix,
  enable_thinking=False). Verified bitwise repeatable across full server
  restarts and spike-victim count 0.
- `greedy_1p7b.json` — same server config without `--sampling-seed`
  (argmax path). Verified bitwise identical to the pre-fix build (greedy
  never draws the uniform) and bitwise matched by all 16 members of a
  `/v1/group_completions` shared-prefix group.
- `RESULTS.txt` — gate output from refv2_analyze.py for the archiving run.

Each JSON records commit, mode, model, exact prompt, request body, and the
full server response (token_ids, prompt_token_ids, per-token logprobs).

8B / 30B references are NOT archived here — regenerate on demand with the
same scripts (`refv2_run.sh <gpu> <pre> <post>` or refv2_client.py against
a hand-launched server).
