Penalty layer: raw fp32 logit, PRE-temperature, before the Gumbel draw.
Formulas: HF repetition first (logit>0 ? logit/rp : logit*rp), then
OpenAI subtraction logit -= presence*(count>0) + frequency*count; counts
from a fixed-order scan of the request's generated tokens only
(tokens[] positions [prompt_len, pos]); prompt tokens not penalized.

Limitations:
- Penalties are compile-time engine defaults (like seed/temperature);
  per-request JSON overrides need a runtime task-param path (none exists).
- Require --sampling-seed; greedy argmax path does not apply them
  (launch_server/MPK raises ValueError if penalties set without seed).
- capture-logprobs prob_buffer reports P(chosen) under the RAW
  (unpenalized) logits: the capture task reads logits independently of
  the sampling task's in-register penalization.
- Full-vocab sampling_sm100 task (not used by the qwen3 builder path)
  did not get penalty params.
